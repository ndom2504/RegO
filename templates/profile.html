📋 Comment obtenir vos identifiants Azure AD ?

Pour synchroniser vos emails Outlook, vous devez créer une application Azure AD :

  • Connectez-vous au portail Azure (portal.azure.com)
  • Accédez à Azure Active Directory → App registrations
  • Créez une nouvelle application et notez le Client ID et Tenant ID
  • Générez un Client Secret dans la section "Certificates & secrets"
  • Ajoutez les permissions API : Mail.Read, Mail.ReadBasic
